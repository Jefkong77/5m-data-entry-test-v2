# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
Kernel is the core part of the operating system and manages resources such as processor time, memory and devices. Kernel acts as a bridge between software applications and computer hardware. For example, when several applications are open, the kernel helps manage their access to these resources.

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not. 

**Answer:**
No, the statement is not accurate. WSL allows you to run a full Linux environment directly alongside Windows without the need for a separate computer. Because WSL actively manages and deeply integrates this Linux environment with the Windows operating system, it is incorrect to describe the two systems as completely separate or totally independent.

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
The terminal emulator (like VS Code’s terminal) provides the interface where you type commands and view output, while the shell (like Bash) is the program that interprets your commands and runs the command or starts the appropriate program.
